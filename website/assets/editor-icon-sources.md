# Editor icon sources

- IntelliJ IDEA and Xcode symbols: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
- Visual Studio icon: [Microsoft Visual Studio product icon](https://visualstudio.microsoft.com/wp-content/uploads/2021/10/Product-Icon.svg).

The Visual Studio Code card uses a generic code-window mark. The published [VS Code brand guidelines](https://code.visualstudio.com/brand) prohibit using the VS Code icon to identify or promote a VS Code extension.
